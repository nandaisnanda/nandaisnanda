A small open-source attempt at making **geospatial QA/QC a little less painful**.

```text
       suspicious.geojson
               │
               ▼
          ┌─────────┐
          │  GeoQC  │ 🧹
          └────┬────┘
               │
      ┌────────┼────────┬──────────┐
      ▼        ▼        ▼          ▼
  geometry    CRS     schema    duplicates
      │        │        │          │
      └────────┴────────┴────┬─────┘
                             ▼
                       QA/QC report
                             │
                             ▼
                     hopefully valid ✨
```

Because this:

```python
gdf.is_valid.all()
```

should **not** be an emotionally significant event.

`noch in Arbeit` · `还在学习` · `still building` 🛠️
